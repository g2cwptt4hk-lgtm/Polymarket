# Polymarket — Personal Practice Simulator

A standalone, local-only prediction-market practice web app.

## Included
- Markets, categories, search and sorting
- Binary YES/NO and multi-outcome markets
- Market and limit orders
- Simulated order book
- Buy and sell positions
- Portfolio valuation and P&L
- Open-order cancellation
- Resolved-market examples and resolved-position history
- Activity history
- Simulated £ wallet with American Express ••••6307 display
- Account/settings area with the practice disclosure kept there
- iPhone Home Screen manifest and supplied Polymarket branding
- LocalStorage persistence

Nothing connects to real money, cards, banks, blockchain, exchanges or an external Polymarket account.
